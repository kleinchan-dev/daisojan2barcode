daisojan2barcode

ダイソーのネットショップの商品ページに、JAN コードのバーコードを自動で表示するユーザースクリプト

Tampermonkey ユーザースクリプトuserscript

バージョン ・最終更新

クリックしてインストール
  • 要 Tampermonkey（Chrome / Edge / Firefox など）
  • 対象: jp.daisonet.com・jpbulk.daisonet.com の商品ページ
  • EAN-13 のチェックディジットが妥当な JAN のみ描画

クリックすると Tampermonkey のインストール画面が開きます。

導入方法

  1. ブラウザに Tampermonkey をインストール
  2. 上の「クリックしてインストール」をクリックし、Tampermonkey のインストール画面で「インストール」
  3. 単品買いの商品ページまたはまとめ買いの商品ページで動作確認

既に開いている商品ページがある場合は再読み込みしてください。

更新

インストール後は Tampermonkey が定期的に同じ URL をチェックし、自動で更新されます。

手動で更新する場合は、Tampermonkey ダッシュボードの「ユーティリティ」タブ →「ユーザースクリプトを更新」を実行してください。
